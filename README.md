# 🌍 WorldTrip - Travel Explorer & Budget Planner

A responsive web application to explore popular travel destinations worldwide and estimate trip budgets.

## 🚀 Features
- **Destination Discovery**: Filter travel spots by continent (Asia, Europe, Americas).
- **Search Filter**: Search by destination city, country, or region in real-time.
- **Budget Estimator**: Quick interactive trip expense calculator.
- **Responsive Design**: Clean UI optimized for desktop and mobile screens.

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox & CSS Grid)
- JavaScript (Vanilla ES6+)
- Font Awesome Icons
- Unsplash API images
